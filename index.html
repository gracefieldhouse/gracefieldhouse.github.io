Installer en trois étapes

  1. 1

    Télécharge l’installateur

    Clique sur « Télécharger pour Windows ». Le fichier GraceFieldHouse-Setup.exe arrive dans tes Téléchargements.

  2. 2

    Lance-le

    Double-clique sur le fichier, accepte la licence et choisis le dossier d’installation. Pas besoin de compte.

  3. 3

    Ouvre l’application

    Un raccourci « Grace Field House » apparaît sur ton Bureau. C’est prêt.

Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires, puis sur Exécuter quand même. Cet avertissement apparaît pour les applications peu connues.

Bon à savoir

  • Windows uniquement. Pas de version Mac ni téléphone.
  • Jeu à plusieurs en local. Tout le monde doit être sur le même réseau.
  • Pas de synchronisation. Ni compte ni serveur : tes données restent chez toi.
  • Tu écris tes questions. Ou tu les colles depuis un texte, sans IA.
  • Cinq langues d’interface. Les QCM fournis sont en français.

Questions

Installateur ou version portable ?

L’installateur est recommandé : l’application démarre plus vite et se désinstalle proprement. La version portable se lance sans installation, depuis une clé USB par exemple, mais elle met plus de temps à s’ouvrir.

C’est vraiment gratuit ?

Oui. Pas de publicité, pas d’abonnement, pas de compte.

Où sont enregistrées mes données ?

Sur ton ordinateur uniquement. Rien n’est envoyé sur Internet.

Comment la désinstaller ?

Paramètres Windows › Applications › Grace Field House › Désinstaller.
